# Programming Black Website

This project is a small multi-page website exploring how computing affects everyday life in different areas, including speech translation, healthcare, remote computing and pathfinding.

## Pages

- `index.html` — home page and overview
- `AISpeechTranslation.html` — AI speech translation topic
- `healthcare.html` — healthcare and digital technology topic
- `RemoteComputing.html` — remote computing topic
- `Pathfinding.html` — navigation and route-planning topic
